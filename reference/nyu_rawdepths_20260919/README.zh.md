# 对齐的真实传感器失效掩码（NYU rawDepths → NYU test654）

2026-09-19。纯推理。**这是本轮三个实验里口径最严的一个，结论对本文方法不利，必须照实写。**

## 1. 映射门（先证明再用）

`nyu_depth_v2_labeled.mat`（官方，2.97 GB，`depths` / `rawDepths` 各 1449×640×480 float32，转置后 480×640）。

DFormer 包的 8-bit Depth PNG 与 mat 的编码公式对不上（MAD 4.8/255，PNG 疑似用裁剪区域算 min-max），
因此**不用编码值做映射判据，改用相关性**：

- id 1090 与 `depths[1090]` 相关 **+0.9974**，与其他索引仅 0.11–0.63。
- 随机抽 25 个 test id，每个与 6 个诱饵索引对比：**25/25 自身索引胜出**，最小 margin **+0.175**。

→ **mat index == 文件 id，恒等映射，已证。** `rawDepths` 可用。

即 `clean`（100% 可用）在真实 Kinect v1 采集中**不存在**。

## 3. 结果（自检三臂全部 PASS，9 位小数）

| 条件 | 可用率 | RGB-only | C | R (ours) | R−C |
|---|---:|---:|---:|---:|---:|
| `raw_aligned`（每图用自己的真实掩码） | 69.3% | 51.65 | **52.80** | 52.66 | **−0.14** |
| `raw_shuffled`（同分布，打乱配对） | 69.3% | 51.64 | **52.71** | 52.54 | −0.17 |

**对齐效应（aligned − shuffled）：RGB-only +0.01 · C +0.09 · R +0.12。**

## 4. 三个必须写进正文的结论

**(1) 真实失效下 C 优于 R。** 69.3% 可用率处 C 52.80 vs R 52.66。本文方法的优势**没有出现在真实工作点上**。

**(2) "空洞专挑难表面所以更伤" 的假设被证伪。** 打乱对照显示对齐效应仅 +0.09/+0.12，
且三个臂**同向、同量级**——把真实掩码贴到错误的场景上，结果几乎不变。
真实失效之所以比合成块温和，原因不是相关性，而是**形态**：真实空洞细碎分散，
大面积平滑区的深度仍保留；合成 rect/multi 抹掉整片连续区域。

**(3) 合成块掩码高估 C 的损伤约 1 点。** 同为 ~69% 可用率：
合成插值 C ≈ 51.4 / R ≈ 52.4（R 胜约 1.0）；真实对齐 C 52.80 / R 52.66（C 胜 0.14）。
这一点同时被 TUM（独立传感器采集，C +0.78）和 NYU rawDepths（对齐）两路证实。

## 5. 一个方法学警告：分层不能当可用率曲线读

按每图自身空洞比例分三档的结果是**非单调**的：

| 档 | n | 可用率 | RGB-only | C | R |
|---|---:|---:|---:|---:|---:|
| tercile1 | 218 | 76.6% | 50.98 | 52.08 | 51.98 |
| tercile2 | 218 | 71.2% | 50.21 | 52.14 | 51.27 |
| tercile3 | 217 | 60.2% | 51.02 | 52.01 | 51.97 |

关键证据：**RGB-only 在三档间波动 0.81 点，而它根本不使用深度**。
这说明档间差异主要来自**场景构成**而非可用率——真实可用率与场景内容相关，
分层把两者混在一起。**只有合成扫描（同一批图、只变可用率）给出干净的可用率轴。**

## 6. 边界

1. 单 seed、单 checkpoint、fit695 训练、480×640 单尺度无翻转、bf16。
2. `rawDepths==0` 是 NYU 官方无效约定；未做额外有效性校验。
3. 两个真实源都是 Kinect v1 室内近景，不覆盖 ToF / 双目 / 户外远景失效模式。
4. 与主表 `t5_core.tex` 的规定值不是同一组结果，不可混用。
